# 户外位置共享 · AR 指向（PeerJS P2P 版）

## 功能

- **发送端**：GPS 定位 + 手机指南针 + 摄像头拍照定点，通过三角交汇（双观测点方位线求交点）或单点+距离两种方式计算目标经纬度，实时推送给同伴
- **接收端**：调用环境摄像头，AR 叠加高亮黄绿色圆环标记指向目标方向；目标偏离视野时屏幕边缘闪烁箭头提示转动方向；底部刻度条显示实时方位
- **多对多**：P2P 全互联，无需中心服务器（仅依赖 PeerJS 免费信令服务做连接握手），支持多人同时收发

## 在线地址

- https://oma-z1-o.github.io/outdoor-location-share/

## 本地运行（可选）

无需服务器，直接用浏览器打开 `index.html` 即可；或任选静态服务：

```bash
npx serve .
```

## 使用方法

1. 发送端与接收端都打开页面（手机浏览器）
2. 各自复制页面顶部的 PeerID，互相粘贴到"连接同伴"输入框后点"连接"
3. 发送端：获取位置 → 启动指南针 → 启动摄像头 → 对准目标拍照/记录观测点 → 计算目标位置 → 推送
4. 接收端：打开摄像头 AR 视图，跟随高亮标记转向目标

## 技术要点

- 信令：PeerJS 官方公共服务器（无需自建）
- NAT 穿越：Google STUN（stun.l.google.com / stun1.l.google.com）
- 数据通道：WebRTC DataChannel（reliable）
- 地理计算：球面方位角/目的地推算 + 局部平面投影三角交汇

## 注意事项

- 摄像头、定位、指南针均要求 HTTPS（GitHub Pages 已满足）
- Android 指南针需手机水平放置并画"8"字校准；iOS 需点击按钮授权
- 野外建议提前打开页面确认 PeerJS 可连；数据流量下可正常使用
- 若公共 PeerJS 信令不稳定，可自行部署 PeerServer（见 https://github.com/peers/peerjs-server）
